# 登录与账号说明

本文档说明 `douyin-spark-client` 登录页的账号类型、默认管理员、注册流程和常见问题。

## 默认管理员

后端内置一个超级管理员账号：

```text
public_uid: 100000
显示名: Admin
默认密码: ad32800
role: admin
```

登录页选择：

```text
登录方式：账户ID登录
账户ID：Admin
密码：ad32800
```

也可以使用：

```text
登录方式：账户ID登录
账户ID：100000
密码：ad32800
```

前端会按输入内容决定请求字段：

```text
输入 6 位数字，例如 100000 -> 提交 public_uid
输入 Admin                 -> 提交 account
```

对应接口：

```text
POST /api/v1/account/login
```

`Admin` 登录请求：

```json
{
  "account": "Admin",
  "password": "ad32800"
}
```

`100000` 登录请求：

```json
{
  "public_uid": "100000",
  "password": "ad32800"
}
```

## 普通用户登录

普通用户推荐使用 QQ 邮箱登录：

```text
登录方式：QQ邮箱登录
QQ邮箱：注册时使用的 QQ 邮箱
密码：注册密码
```

请求：

```json
{
  "qq_email": "123456789@qq.com",
  "password": "password"
}
```

如果后端支持普通用户 `public_uid + password` 登录，也可以切换到“账户ID登录”并输入普通用户的 6 位账户 ID。

后端内置测试普通账号：

```text
账户ID：100001
密码：a100001

账户ID：100002
密码：a100002
```

这些账号可用于本地联调普通用户流程，例如查看通知、联系管理员、添加抖音号。

## 普通用户注册

注册流程：

```text
1. 输入 QQ 邮箱
2. 点击“发送验证码”
3. 从 QQ 邮箱或后端控制台日志获取验证码
4. 输入验证码和密码
5. 点击“注册并登录”
```

密码规则以后端接口为准，当前规则是：

```text
长度 6-20 个字符
必须至少包含 1 个数字
必须至少包含 1 个非数字字符
只允许大小写字母、数字、英文点号 .、下划线 _、短横线 -
不允许空格
不允许中文和其他符号
```

如果后端没有启用 QQ 邮箱 SMTP 配置，验证码不会真的发到邮箱，而是打印在后端控制台日志里。

## 忘记密码

登录页提供“忘记密码”页签。当前后端支持的是：

```text
QQ 邮箱验证码重置密码
```

流程：

```text
1. 输入 QQ 邮箱
2. 点击“发送验证码”
3. 从 QQ 邮箱或后端控制台日志获取验证码
4. 输入验证码和新密码
5. 点击“重置密码”
6. 回到登录页，用新密码登录
```

对应接口：

```text
POST /api/v1/account/reset-password-code
POST /api/v1/account/reset-password
```

当前后端暂未提供“QQ 邮箱验证码直接登录”的接口，所以前端不会展示“验证码登录”按钮，避免用户误以为验证码可以绕过密码直接登录。

## 注册提示“资源状态冲突”

如果注册时报：

```text
当前资源状态冲突
```

常见原因是：

```text
这个 QQ 邮箱已经注册过。
```

处理方式：

- 切换到“登录”页签，用该 QQ 邮箱和密码登录。
- 或换一个未注册过的 QQ 邮箱重新注册。

如果你刚刚点击了“发送验证码”，但验证码没有收到，也要先看后端控制台日志；开发模式下验证码可能打印在日志里。

## 管理员登不上时怎么排查

先确认后端健康检查正常：

```powershell
Invoke-RestMethod -Method Get -Uri http://127.0.0.1:8787/health
```

成功时返回：

```json
{
  "status": "ok"
}
```

再直接测试管理员接口：

```powershell
$body = @{ account = 'Admin'; password = 'ad32800' } | ConvertTo-Json
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8787/api/v1/account/login -ContentType 'application/json' -Body $body
```

或者测试 `public_uid`：

```powershell
$body = @{ public_uid = '100000'; password = 'ad32800' } | ConvertTo-Json
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8787/api/v1/account/login -ContentType 'application/json' -Body $body
```

如果接口能登录但页面不能登录，优先检查前端是否已经重新构建或刷新页面。

开发模式下运行：

```powershell
npm.cmd run dev -- --port 5173
```

然后刷新：

```text
http://127.0.0.1:5173/login
```

## QQ 邮箱红色波浪线

如果输入框里的 `@qq.com` 出现红色波浪线，这通常是浏览器拼写检查，不是前端校验错误，也不是后端错误。

前端已经给 QQ 邮箱输入框设置：

```text
spellcheck=false
autocapitalize=off
autocomplete=email
```

如果仍然看到红色波浪线，可以刷新页面或关闭浏览器输入法/拼写检查扩展。

## 当前登录页设计

登录页有两种互斥登录方式：

```text
账户ID登录
QQ邮箱登录
```

一个输入框只表示一种登录方式。切换登录方式时，前端会清空账号输入框，避免把 QQ 邮箱当账户 ID 或把账户 ID 当 QQ 邮箱提交。
