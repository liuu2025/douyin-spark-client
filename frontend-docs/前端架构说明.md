# 前端架构说明

本文档说明当前前端项目的结构、页面闭环、权限边界和后续扩展位置。后端接口准则仍以 `docs-后端生成的说明文档/HTTP接口文档.md` 为准；本目录只记录前端实现。

## 目录结构

```text
src/
  api/              HTTP client、接口封装和类型
  components/       可复用业务组件
  layouts/          控制台外壳
  router/           路由和权限守卫
  stores/           Pinia 状态
  styles/           全局样式
  utils/            状态文案映射等工具
  views/            页面组件
```

关键文件：

- `src/api/http.ts`：Axios 实例、Bearer Token 注入、错误码翻译。
- `src/stores/auth.ts`：登录态、当前用户、管理员判断、退出登录。
- `src/router/index.ts`：路由表、登录守卫、管理员权限守卫。
- `src/layouts/ConsoleLayout.vue`：左侧导航、顶部栏、通知入口、账号下拉和退出。
- `src/components/LoginSessionDrawer.vue`：远程浏览器登录状态机。
- `src/components/SendTaskDialog.vue`：发送任务轻量配置表单。

## 页面布局

登录后统一进入控制台布局：

```text
左侧导航 + 顶部账号栏 + 主内容区
```

普通用户菜单：

```text
仪表盘
抖音号
消息中心
账号设置
```

管理员额外菜单：

```text
管理员
  登录态导入
  通知发布
  用户咨询
```

管理员和普通用户都通过右上角账号下拉退出登录。

## 抖音号页面闭环

抖音号相关操作拆成两个层级：

```text
/douyin-accounts
  只显示抖音号列表和摘要。
  点击“进入”后跳转到单个抖音号详情。

/douyin-accounts/:douyinId
  当前页面只管理一个 douyin_id。
  包含登录状态、验证、重新登录、自动发送、发送任务和运行记录。
```

这样可以避免在同一个页面同时操作多个抖音号，降低误操作风险。

## 远程浏览器登录

新增抖音号和重新登录共用 `LoginSessionDrawer`。

流程：

```text
打开抽屉
  -> 自动调用 POST /login-sessions
  -> 如果返回 remote_url，打开新标签页
  -> 轮询 GET /login-sessions/{id}
  -> waiting_manual_login：提示用户在远程浏览器中登录
  -> login_confirming：提示确认滑块/风控/保存登录信息弹窗已处理
  -> 用户点击确认：POST /login-sessions/{id}/confirm
  -> finalizing：等待服务端保存和绑定
  -> logged_in：刷新抖音号数据
```

取消时调用：

```text
POST /login-sessions/{id}/cancel
```

如果会话仍在进行中，抽屉不允许直接关闭，会提示用户先取消登录，避免远程浏览器资源悬挂。

## 发送任务

第一版发送任务做轻量配置：

- 消息模板。
- 时间格式。
- 发送周期秒数。
- 启用状态。
- `target_rules_json` 高级 JSON 输入。

目标规则暂未产品化为好友/群聊表单，因为当前还没有确定完整规则 schema。后续如果后端或产品明确规则结构，可把 `SendTaskDialog` 拆成结构化表单。

## 消息和通知

消息中心、管理员通知发布、用户咨询页面已经接入真实 HTTP 接口。

当前能力：

- `/messages`：普通用户和管理员查看系统通知；普通用户联系管理员；管理员查看用户咨询摘要。
- `/admin/notices`：管理员发布通知并查看已发布通知。
- `/admin/support`：管理员查看会话列表、读取消息并回复普通用户。

当前仍未实现：

- 未读通知数量。
- 通知归档或删除。
- 消息已读状态。
- WebSocket/SSE 实时推送。

## 权限规则

路由权限：

- `meta.public`：无需登录，例如 `/login`。
- `meta.admin`：仅管理员可访问。
- 未登录访问控制台页面会跳转 `/login`。
- 普通用户访问管理员页面会跳转 `/dashboard`。

UI 权限：

- 管理员菜单只在 `user.role === 'admin'` 时显示。
- 普通用户没有登录态导入入口。

## 状态文案

状态文案统一在 `src/utils/status.ts` 中维护。

登录状态映射：

```text
not_checked             未验证
ok                      有效
not_logged_in           已失效
missing_storage_state   登录文件缺失
identity_mismatch       账号不匹配
check_failed            验证失败
transferred             已转移
```

登录会话状态映射：

```text
remote_browser_starting  正在启动远程浏览器
waiting_manual_login     等待用户在远程浏览器中完成登录
login_confirming         已检测到登录成功，等待确认
finalizing               正在保存最终登录状态
logged_in                登录完成
cancelled                已取消
failed                   登录失败
timeout                  会话超时
```
