# 接口接入说明

本文档记录前端如何使用后端接口。接口字段和最终准则以 `docs-后端生成的说明文档/HTTP接口文档.md` 为准。

## 基础规则

开发环境请求路径：

```text
/api/v1
```

Vite 代理：

```text
/api/v1 -> http://127.0.0.1:8787/api/v1
```

登录后所有受保护接口通过 Bearer Token：

```http
Authorization: Bearer <token>
```

Token 存储在 `localStorage`，key 为：

```text
douyin_spark_token
```

应用启动时，如果本地存在 token，会调用：

```text
GET /api/v1/account/me
```

校验失败时清空 token 并回到登录页。

## 账号接口

登录：

```text
POST /api/v1/account/login
```

账户 ID 登录时前端提交：

```json
{
  "account": "Admin",
  "password": "ad32800"
}
```

QQ 邮箱登录时前端提交：

```json
{
  "qq_email": "123456789@qq.com",
  "password": "password"
}
```

注册：

```text
POST /api/v1/account/register-code
POST /api/v1/account/register
```

忘记密码：

```text
POST /api/v1/account/reset-password-code
POST /api/v1/account/reset-password
```

当前后端暂未提供邮箱验证码直接登录接口，前端只实现重置密码，不实现验证码登录。

退出：

```text
POST /api/v1/account/logout
```

退出时即使服务端 token 已失效，前端也会清空本地 token 并跳转 `/login`。

## 抖音号接口

列表：

```text
GET /api/v1/douyin-accounts
```

详情：

```text
GET /api/v1/douyin-accounts/{douyin_id}
```

读取最近一次登录状态：

```text
GET /api/v1/douyin-accounts/{douyin_id}/login-status
```

立即验证登录状态：

```text
POST /api/v1/douyin-accounts/{douyin_id}/login-status
```

自动发送开关：

```text
PATCH /api/v1/douyin-accounts/{douyin_id}/polling
```

请求体：

```json
{
  "enabled": true
}
```

前端只提交 `douyin_id`，不提交任何服务端文件路径。

## 远程浏览器登录接口

创建会话：

```text
POST /api/v1/login-sessions
```

查询会话：

```text
GET /api/v1/login-sessions/{session_id}
```

确认完成登录：

```text
POST /api/v1/login-sessions/{session_id}/confirm
```

取消会话：

```text
POST /api/v1/login-sessions/{session_id}/cancel
```

前端行为：

- 创建会话后读取 `remote_url`。
- 用 `window.open(remote_url, "_blank")` 打开远程浏览器。
- 轮询会话状态。
- `login_confirming` 时允许用户点击确认。
- 用户取消时调用 cancel。
- `logged_in` 后刷新抖音号数据。

不使用的旧兼容接口：

```text
GET  /api/v1/login-sessions/{session_id}/qr-image
POST /api/v1/login-sessions/{session_id}/sms-code
POST /api/v1/login-sessions/{session_id}/resend-sms
```

第一版前端不展示二维码，也不展示短信验证码输入框。

## 发送任务接口

列表：

```text
GET /api/v1/douyin-accounts/{douyin_id}/send-tasks
```

创建：

```text
POST /api/v1/douyin-accounts/{douyin_id}/send-tasks
```

请求体：

```json
{
  "message_template": "你好，现在是 {{datetime}}",
  "datetime_format": "2006-01-02 15:04",
  "target_rules_json": "[]",
  "schedule_mode": "cycle_random",
  "cycle_seconds": 300,
  "enabled": true
}
```

修改：

```text
PATCH /api/v1/send-tasks/{task_id}
```

暂停：

```text
POST /api/v1/send-tasks/{task_id}/pause
```

恢复：

```text
POST /api/v1/send-tasks/{task_id}/resume
```

运行记录：

```text
GET /api/v1/send-tasks/{task_id}/runs
GET /api/v1/douyin-accounts/{douyin_id}/send-runs
```

前端只提交 `douyin_id` 或 `task_id`，不提交 `storageState.json` 路径。

## 管理员登录态导入

仅管理员可访问：

```text
POST /api/v1/admin/storage-state-imports
```

请求类型：

```http
Content-Type: multipart/form-data
```

表单字段：

```text
target_public_uid=100002
storage_state=<storageState.json 文件>
```

前端展示导入结果：

- `status`
- `result`
- `target_public_uid`
- `detected_douyin_id`
- `owner_changed`
- `last_error_code`
- `last_error_message`

即使后端返回 `final_storage_state_path`，前端也不需要展示它。

## 通知公告

通知公告已经接入后端。普通用户和管理员都可以读取已发布通知：

```text
GET /api/v1/notices
```

管理员通知管理：

```text
GET  /api/v1/admin/notices
POST /api/v1/admin/notices
```

发布通知请求：

```json
{
  "title": "系统维护",
  "content": "今晚 23:00 维护。"
}
```

限制：

```text
title 最多 120 个字符
content 最多 5000 个字符
```

## 用户联系管理员

客服聊天已经接入后端，当前是 HTTP 刷新/轮询模型，不是 WebSocket 实时聊天。

普通用户入口：

```text
GET  /api/v1/support/messages
POST /api/v1/support/messages
```

发送消息请求：

```json
{
  "content": "我需要帮助"
}
```

管理员入口：

```text
GET  /api/v1/admin/support/conversations
GET  /api/v1/admin/support/conversations/{public_uid}/messages
POST /api/v1/admin/support/conversations/{public_uid}/messages
```

管理员回复请求：

```json
{
  "content": "收到，我来看看。"
}
```

限制：

```text
content 最多 3000 个字符
普通用户只能调用 /support/messages
管理员只能通过 /admin/support/... 查看和回复用户咨询
```

## 暂未接入的后端能力

以下页面已有前端布局，但后端接口尚未实现：

- 通知未读数量。
- 通知归档或删除。
- 客服消息已读状态。
- WebSocket/SSE 实时推送。

当前前端使用手动刷新和页面打开时加载，不做实时推送假状态。

## 错误处理

后端错误格式：

```json
{
  "error": {
    "code": "not_found",
    "message": "资源不存在"
  }
}
```

前端在 `src/api/http.ts` 中统一转换错误，并对常见错误码做中文映射。

常见前端提示：

```text
unauthorized              登录已失效，请重新登录。
admin_required            当前操作需要管理员权限。
remote_login_disabled     远程浏览器登录未启用。
login_state_not_ok        抖音登录状态不可用，请先验证或重新登录。
target_user_disabled      目标客户端账号已禁用。
normal_user_required      该接口只允许普通用户调用。
target_user_must_be_normal 客服会话目标必须是普通用户。
```
